# TokenVector UI Design
> Thư mục chứa toàn bộ kế hoạch, tài liệu thiết kế và mã nguồn UI của TokenVector.

## 📂 Cấu trúc thư mục

```
TokenVector_UI_Design/
├── UI_ROADMAP.md          ← Kế hoạch phát triển 4 giai đoạn (đọc đây trước)
├── phase1_tui/            ← TUI Console stdlib modules (.tkv)
├── phase2_webui/          ← Web UI Bridge (tkv_http, tkv_webview templates)
├── phase3_native_gui/     ← Native Desktop GUI widgets (.tkv)
└── phase4_crossplatform/  ← SDL2 / Raylib C-FFI bindings
```

## 🚀 Bắt đầu từ đâu?

Đọc file [`UI_ROADMAP.md`](./UI_ROADMAP.md) để nắm toàn bộ kế hoạch.  
Sau đó bắt đầu thực hiện **Phase 1** trong thư mục `phase1_tui/`.
