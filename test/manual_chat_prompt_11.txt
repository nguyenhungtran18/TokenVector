CHI viet than ham (khong lap lai dong chu ky).

1. Chu ky: unique_char_count(s: str) -> i32:
   Yeu cau: Dung dict de danh dau ky tu da gap, tra ve SO LUONG ky tu KHAC NHAU trong chuoi s.
   -> dat trong khoi ```dsl:unique_char_count ... ```

2. Chu ky: list_max(a: i32, b: i32, c: i32) -> i32:
   Yeu cau: Tao 1 list rong, them 3 so a, b, c vao list, roi duyet list de tim va tra ve GIA TRI LON NHAT trong 3 so do.
   -> dat trong khoi ```dsl:list_max ... ```

3. Chu ky: list_count_even(n: i32) -> i32:
   Yeu cau: Tao list gom cac so tu 0 den n-1, duyet list va dem so luong phan tu CHAN (dung phep chia lay du % voi 2), tra ve so dem do.
   -> dat trong khoi ```dsl:list_count_even ... ```

4. Chu ky: dict_sum_values(a: i32, b: i32, c: i32) -> i32:
   Yeu cau: Tao 1 dict rong, gan d["x"]=a, d["y"]=b, d["z"]=c, roi tra ve TONG 3 gia tri trong dict (doc lai tung khoa).
   -> dat trong khoi ```dsl:dict_sum_values ... ```

5. Chu ky: dict_has_key_report(a: i32, key_present: i32) -> str:
   Yeu cau: Tao 1 dict rong, gan d["val"]=a. Neu key_present khac 0 THEM gan d["extra"]=1. Kiem tra "extra" in d, neu co tra ve chuoi "co extra", neu khong tra ve "khong co extra".
   -> dat trong khoi ```dsl:dict_has_key_report ... ```

6. Chu ky: list_of_squares_sum(n: i32) -> i32:
   Yeu cau: Tao list rong, dung vong lap them binh phuong tung so tu 0 den n-1 vao list, roi duyet list de tra ve TONG tat ca binh phuong do.
   -> dat trong khoi ```dsl:list_of_squares_sum ... ```

7. Chu ky: gcd_like_mod(a: i32, b: i32) -> i32:
   Yeu cau: Dung vong lap while: trong khi b khac 0, tinh r = a chia lay du cho b (dung %), gan a = b, gan b = r. Khi vong lap ket thuc tra ve a (gia tri GCD kieu Euclid).
   -> dat trong khoi ```dsl:gcd_like_mod ... ```

8. Chu ky: clamp_report(x: i32, lo: i32, hi: i32) -> str:
   Yeu cau: Neu x < lo, tra ve chuoi "duoi min: " noi voi str(lo). Neu x > hi, tra ve chuoi "tren max: " noi voi str(hi). Neu khong, tra ve chuoi "trong khoang: " noi voi str(x).
   -> dat trong khoi ```dsl:clamp_report ... ```

9. Chu ky: safe_index_report(n: i32, idx: i32) -> str:
   Yeu cau: Tao list gom cac so tu 0 den n-1. Trong khoi try, neu idx < 0 hoac idx >= n thi TU NEM raise IndexError("chi so ngoai pham vi"). Bat loi bang except IndexError: tra ve chuoi "loi: chi so khong hop le". Neu khong loi, tra ve "gia tri: " noi voi str(list[idx]).
   -> dat trong khoi ```dsl:safe_index_report ... ```

10. Chu ky: count_not_equal(a: i32, n: i32) -> i32:
   Yeu cau: Tao list gom cac so tu 0 den n-1, duyet list va DEM so phan tu MA khong bang a (dung "not (phan_tu == a)"), tra ve so dem do.
   -> dat trong khoi ```dsl:count_not_equal ... ```

11. Chu ky: running_total_capped(n: i32, cap: i32) -> i32:
   Yeu cau: Dung 1 bien tong bat dau tu 0, vong lap i tu 0 den n-1: tong += i (gan rut gon). Neu tong > cap thi break ra khoi vong lap ngay. Tra ve tong cuoi cung.
   -> dat trong khoi ```dsl:running_total_capped ... ```
