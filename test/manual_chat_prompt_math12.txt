CHI viet than ham (khong lap lai dong chu ky). Domain: toan hoc/so hoc co ban.

1. Chu ky: is_prime(n: i32) -> i32:
   Yeu cau: Kiem tra n co phai so nguyen to khong (chi chia het cho 1 va chinh no, n<2 la khong phai), tra ve 1 neu la so nguyen to, 0 neu khong. Dung vong lap for tu 2 den n-1 (hoac toi uu hon neu muon) kiem tra chia het bang %.
   -> dat trong khoi ```dsl:is_prime ... ```

2. Chu ky: count_primes_upto(n: i32) -> i32:
   Yeu cau: Dem so luong so nguyen to nho hon n (tu 2 den n-1), tra ve so luong do. Co the viet ham phu is_prime_inline logic ngay trong vong lap (khong goi ham ngoai, DSL nay chua ho tro goi ham tu dinh nghia khac trong cung 1 doan).
   -> dat trong khoi ```dsl:count_primes_upto ... ```

3. Chu ky: gcd_euclid(a: i32, b: i32) -> i32:
   Yeu cau: Tinh uoc chung lon nhat (GCD) cua a va b bang thuat toan Euclid (vong lap while, dung phep chia lay du %).
   -> dat trong khoi ```dsl:gcd_euclid ... ```

4. Chu ky: lcm_via_gcd(a: i32, b: i32) -> i32:
   Yeu cau: Tinh boi chung nho nhat (LCM) cua a va b, dung cong thuc LCM = a*b/gcd(a,b). Tinh gcd truoc bang vong lap while (thuat toan Euclid) ngay trong than ham nay, roi tinh LCM.
   -> dat trong khoi ```dsl:lcm_via_gcd ... ```

5. Chu ky: is_perfect_square(n: i32) -> i32:
   Yeu cau: Kiem tra n co phai so chinh phuong khong (co can bac 2 nguyen), tra ve 1 neu co 0 neu khong. Dung vong lap for i tu 0, kiem tra i*i == n hoac i*i > n thi dung (khong dung ham sqrt de tranh sai so).
   -> dat trong khoi ```dsl:is_perfect_square ... ```

6. Chu ky: sum_of_digits(n: i32) -> i32:
   Yeu cau: Tinh tong cac chu so cua n (so nguyen duong), dung vong lap while lay chu so cuoi bang % 10 roi chia nguyen cho 10 (dung phep / cho i32 la chia nguyen).
   -> dat trong khoi ```dsl:sum_of_digits ... ```

7. Chu ky: reverse_number(n: i32) -> i32:
   Yeu cau: Dao nguoc cac chu so cua so nguyen duong n (vd 123 -> 321), dung vong lap while, % 10 va / 10.
   -> dat trong khoi ```dsl:reverse_number ... ```

8. Chu ky: is_palindrome_number(n: i32) -> i32:
   Yeu cau: Kiem tra n co phai so doi xung (palindrome) khong bang cach dao nguoc no roi so sanh voi n ban dau, tra ve 1 neu doi xung 0 neu khong.
   -> dat trong khoi ```dsl:is_palindrome_number ... ```

9. Chu ky: power_int(base: i32, exp: i32) -> i32:
   Yeu cau: Tinh base mu exp (exp >= 0) bang vong lap nhan don gian (khong dung ham pow co san, DSL chua ho tro), tra ve ket qua.
   -> dat trong khoi ```dsl:power_int ... ```

10. Chu ky: fibonacci_nth(n: i32) -> i32:
   Yeu cau: Tinh so Fibonacci thu n (F(0)=0, F(1)=1, F(2)=1,...) bang vong lap (khong de quy), dung 2 bien luu 2 so lien tiep.
   -> dat trong khoi ```dsl:fibonacci_nth ... ```

11. Chu ky: collatz_steps(n: i32) -> i32:
   Yeu cau: Dem so buoc trong day Collatz bat dau tu n cho den khi ve 1 (neu chan chia 2, neu le nhan 3 cong 1), tra ve so buoc.
   -> dat trong khoi ```dsl:collatz_steps ... ```

12. Chu ky: digital_root(n: i32) -> i32:
   Yeu cau: Tinh can so hoc (digital root) cua n: cong lien tuc cac chu so cho den khi con 1 chu so (dung vong lap while ket hop ham tinh tong chu so ben trong).
   -> dat trong khoi ```dsl:digital_root ... ```
