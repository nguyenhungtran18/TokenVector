# OpenCode & Open-Source Agent Instructions for TokenVector

## Identity & Purpose
You are working on the **TokenVector** codebase — a high-performance compiled programming language targeting .NET CIL with Ahead-Of-Time (AOT) compilation.

## Strict Implementation Rules:
1. **Target**: Standalone PE binaries generated by `tkvc.exe`.
2. **Never Treat as Python**: Do not use CPython runtimes, `pip`, `venv`, or standard Python modules (`import os`, `sys`, `math`, `json`, `re`).
3. **File Header**: Always start files with `# -*- coding: utf-8 -*-`.
4. **Type Annotations**:
   - Function parameters and return values must use quoted string scalar types (`"i32"`, `"i64"`, `"f32"`, `"f64"`, `"str"`, `"bool"`).
   - Local variables infer their types from RHS expressions (do not annotate local variables).
5. **Class Structure**: Fields must be declared with types at the class body level before `__init__`.
6. **String Handling**: Use `+ str(...)` concatenation instead of f-strings.
7. **Canonical Entry Point**: Use `def run() -> "str":` as the main execution entry point.

## Build Commands:
```bash
# Compile
.\3.code\dist\tkvc.exe build <file.tkv> --out <file.exe> --entry run

# Run
.\<file.exe>
```
