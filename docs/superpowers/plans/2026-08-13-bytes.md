# `bytes` literal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `data = b"AB"` — literal ASCII, tạo `List<uint8>` bất biến điền sẵn tại compile-time; đọc (`len`/index/`for-in`) dùng chung hạ tầng `bytearray`; `.append()`/mutate → lỗi rõ.

**Architecture:** Thêm token `BYTES` vào `_EXPR_TOKEN_RE` (`il_core.py`, tokenizer biểu thức DÙNG CHUNG toàn bộ `il_features/*.py` — KHÁC `typed_dsl_parser.py`, đó chỉ parse chữ ký kiểu). AST node `('bytes_lit', v)`. Điểm gán biến mới (`declare_scalar`, `il_codegen.py` dòng ~2734) thêm nhánh `rhs_node[0] == 'bytes_lit'` → `TypeAnn('i32', 'bytes')`. Codegen unroll N lệnh `Add()` hằng số biết trước (không vòng lặp runtime). Đọc/mutate tái dùng + mở rộng guard đã có từ `bytearray` (commit `3773217`).

**Tech Stack:** Python compiler, self-hosted `.tkv` mirror, CIL/`ilasm`.

## Global Constraints

- Sửa đồng bộ cả 2 cây. KHÔNG rebuild `tkvc.exe`.
- Chỉ literal `b"..."` ASCII (0-127) gán trực tiếp vào biến MỚI — không `bytes(x)` constructor, không nối `+`.
- `.append()`/mutate trên `bytes` → `SyntaxError` bất biến rõ ràng.
- `bytearray`/`list[i32]`/`str` thường không đổi hành vi.

- [ ] **Step 1: Điều tra TRƯỚC KHI VIẾT** — đọc `il_core.py`'s `_EXPR_TOKEN_RE`/`_parse_factor_primary`'s nhánh `k == 'STR'` (mẫu `str_lit`), VÀ tìm hàm xử lý escape hiện có cho string literal thật (dùng lúc `ldstr` — grep cách `str_lit` được UNESCAPE trước khi sinh `ldstr` trong `il_codegen.py`/`tkvstr.py`, TÁI DÙNG hàm đó cho `bytes_lit` thay vì viết escape logic mới). - [ ] **Step 2: Token + AST** — thêm `(?P<BYTES>b"(?:[^"\\]|\\.)*")` vào `_EXPR_TOKEN_RE`, ĐẶT TRƯỚC group `ID` (thứ tự alternation quyết định — xác nhận bằng cách viết 1 test tokenize nhanh `b"AB"` KHÔNG bị tách thành `ID('b')`+`STR`). - [ ] **Step 3: `bytes_type.py`** — hàm `parse_bytes_literal(raw: str) -> list[int]`: bỏ tiền tố `b"`/`"` cuối, tái dùng hàm unescape đã xác nhận ở Step 1, với MỖI ký tự kết quả: `ord(ch)`; nếu `> 127` → `SyntaxError` rõ ("bytes literal chi ho tro ASCII").

- [ ] **Step 4: `declare_scalar`'s nhánh `bytes_lit`** — thêm `elif rhs_node[0] == 'bytes_lit': ta = TypeAnn('i32', 'bytes')` (đặt CẠNH nhánh `_record_is_record_ctor_rhs` hiện có, TRƯỚC nhánh `else` suy dtype chung), gắn `known_shapes` tương ứng nếu cơ chế đó cũng cần cập nhật (xác nhận qua Step 1).

- [ ] **Step 5: Codegen gán RHS `bytes_lit`** — theo mẫu Step 1 tìm được: `newobj {il_bytearray_type()}::.ctor()`, rồi với MỖI byte value: `dup`, `ldc.i4 {value}`, `conv.u1`, `callvirt instance void {il_bytearray_type()}::Add(!0)`, cuối cùng `store_var`.

- [ ] **Step 6: Đọc + chặn mutate** — mở rộng các điểm ĐÃ SỬA ở task `bytearray` (grep commit `3773217`'s diff hoặc trực tiếp đọc lại `il_type_str`/`_expr_index`/2 điểm `len()`) để nhận `shape in ('bytearray', 'bytes')` cho ĐỌC.
