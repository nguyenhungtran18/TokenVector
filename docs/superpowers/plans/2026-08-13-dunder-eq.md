# __eq__ cho record Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `a == b`/`a != b` với `a`/`b` cùng kiểu record có định nghĩa
`def __eq__(self, other) -> "i32": ...` sẽ TỰ ĐỘNG gọi method đó thay
vì so sánh reference. Đóng mục thứ 2 trong 5 dunder của 6.5
(`docs/PYTHON_GAP_CHECKLIST.md`).

**Architecture:** Sửa `compile_compare`
(`compiler/il_features/operators.py`) — khi `op in ('==', '!=')` và
`operand_dtype` là tên 1 record có `__eq__`, validate chữ ký rồi sinh
`callvirt instance int32 {owner}::__eq__({record_type})` thay vì
`ceq`/`bne.un` mặc định (so sánh reference). `owner` qua
`_method_owner_class` (đã dùng cho `__str__`, hỗ trợ kế thừa).

**Tech Stack:** Python 3 (compiler), CIL text + `ilasm.exe` (.NET
Framework mscorlib v4.0.30319).

## Global Constraints

- TUYỆT ĐỐI KHÔNG build/rebuild `release/3.code/dist/tkvc.exe`.
- Cả 2 cây `compiler/` (`.py`) và `release/3.code/compiler/` (`.tkv`)

- Record KHÔNG có `__eq__` PHẢI vẫn so sánh reference như cũ (không
  phải lỗi, hành vi mặc định).
- Chỉ `==`/`!=` — không ảnh hưởng `<`/`>`/`<=`/`>=`.
- Không refactor phần nào khác của `operators.py` ngoài `compile_compare`.
- **BÀI HỌC từ `__str__` (sub-project trước)**: khi thêm dispatch mới
  vào 1 điểm trung tâm, PHẢI kiểm tra CÓ điểm dispatch NÀO KHÁC "song
  song" bỏ qua điểm trung tâm đó không (batch `__str__` phát hiện

  `__eq__`, kiểm tra kỹ xem có đường so sánh `==`/`!=` NÀO KHÁC ngoài

  cùng hàm này không, hay có short-circuit riêng nào khác) TRƯỚC khi
  coi Task hoàn thành.

(dòng 293-317 hiện tại):

```python
def compile_compare(node, scope, out, dtype, ctx=None):
    """EXPR_CODEGEN entry cho tag 'compare' - nhanh string uy quyen ra
    ctx['compile_compare_str'] (string_feature.py), phan con lai (so
    sanh so hoc) o day. Ket qua LUON la int32 0/1 (khong phai dtype cua
    toan hang) - dung ceq/cgt/clt CHUAN CIL, cac toan tu con lai
    (!=,>=,<=) suy tu 3 cai do bang 1 lan phu dinh (ldc.i4.0; ceq).
    __eq__ cho record (6.5, dunder overload - muc 2, 2026-08-13): '=='/
    '!=' tren 2 gia tri CUNG kieu record co __eq__(self, other) -> "i32"
    goi callvirt thay vi ceq (reference-compare mac dinh)."""
    op, left, right = node[1], node[2], node[3]
    operand_dtype = ctx['resolve_compare_operand_dtype'](
        left, right, scope, (ctx or {}).get('func_table'), dtype,
        (ctx or {}).get('records'), (ctx or {}).get('record_methods'))
    if operand_dtype == 'str':
        return ctx['compile_compare_str'](op, left, right, scope, out, ctx)
    if operand_dtype == 'int':
        return _int_type.compile_compare(op, left, right, scope, out, ctx)
    compile_expr = ctx['compile_expr']
    records = (ctx or {}).get('records') or {}
    if op in ('==', '!=') and operand_dtype in records:
        record_methods = (ctx or {}).get('record_methods') or {}
        dunder = record_methods.get(operand_dtype, {}).get('__eq__')
        if dunder is not None:
            if len(dunder.params) != 1 or dunder.params[0].type_ann.dtype != operand_dtype or \
                    dunder.params[0].type_ann.shape != 'record' or \
                    dunder.return_type is None or dunder.return_type.dtype != 'i32' or \
                    dunder.return_type.shape is not None:
                raise SyntaxError(
                    f"il_codegen: record '{operand_dtype}' co __eq__ nhung chu ky sai - can "
                    f"dung 1 tham so CUNG kieu record va tra ve \"i32\" "
                    f"('def __eq__(self, other) -> \"i32\":')")
            compile_expr(left, scope, out, operand_dtype, ctx)
            compile_expr(right, scope, out, operand_dtype, ctx)
            from il_features.record_feature import _method_owner_class
            owner = _method_owner_class(ctx, operand_dtype, '__eq__')
            out.append(f'    callvirt instance int32 {owner}::__eq__({operand_dtype})')
            if op == '!=':
                out.append('    ldc.i4.0')
                out.append('    ceq')
            return
    compile_expr(left, scope, out, operand_dtype, ctx)
    compile_expr(right, scope, out, operand_dtype, ctx)
    compare_opcode, compare_negated = ctx['compare_opcode'], ctx['compare_negated']
    if op in compare_opcode:
        out.append(f'    {compare_opcode[op]}')
    else:
        out.append(f'    {compare_negated[op]}')
        out.append('    ldc.i4.0')
        out.append('    ceq')
```

**LƯU Ý param type IL cho `callvirt`**: `{operand_dtype}` dùng trực
tiếp làm tên tham số kiểu record trong chữ ký `callvirt` — đối chiếu
lại với cách `compile_method_call` (`record_feature.py`, dòng ~294
`params_il = ', '.join(il_type_str(p.type_ann) for p in m_sig.params)`)
sinh chữ ký tham số record THẬT (dùng `ctx['il_type_str'](p.type_ann,
records)` trả về dạng `class {TenRecord}`, KHÔNG PHẢI chỉ tên trần) —
SỬA lại đoạn `callvirt` trên dùng
`ctx['il_type_str'](dunder.params[0].type_ann, records)` thay vì
`{operand_dtype}` trần nếu 2 cách cho ra chuỗi khác nhau (kiểm tra kỹ

```python
__tkv_import__ = ["tkv_test_lib"]


class Point:
    x: "i32"
    y: "i32"

    def __eq__(self, other) -> "i32":
        if self.x == other.x:
            if self.y == other.y:
                return 1
        return 0


class Base:
    val: "i32"

    def __eq__(self, other) -> "i32":
        if self.val == other.val:
            return 1
        return 0


class Sub(Base):
    extra: "i32"


class NoEq:
    v: "i32"


def run() -> "i32":
    total = 0
    tested = 0

    p1 = Point(1, 2)
    p2 = Point(1, 2)
    p3 = Point(9, 9)
    tested = tested + 1
    total = total + check("eq_same_content", str(p1 == p2), "1")
    tested = tested + 1
    total = total + check("eq_diff_content", str(p1 == p3), "0")
    tested = tested + 1
    total = total + check("ne_uses_eq_negated", str(p1 != p3), "1")

    s1 = Sub(5, 10)
    s2 = Sub(5, 20)
    tested = tested + 1
    total = total + check("inherited_dunder_eq", str(s1 == s2), "1")

    n1 = NoEq(7)
    n2 = NoEq(7)
    tested = tested + 1
    total = total + check("no_eq_reference_compare", str(n1 == n2), "0")

    return test_summary("dunder_eq_test", total, tested)
```
