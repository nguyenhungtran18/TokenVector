# Debug PDB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cờ `--debug` (mặc định TẮT) trên `tkv.py build` sinh thêm 1 file
`.pdb` cạnh `.exe`, cho phép breakpoint THẬT trên từng dòng source
`.tkv`/`.py` gốc trong debugger native (Visual Studio) — build mặc định
(không `--debug`) hoàn toàn không đổi.

**Architecture:** Giữ số dòng gốc (tuyệt đối, tính từ `ast.FunctionDef`'s
`lineno`) xuyên suốt `_strip_lines`→`_parse_block`, gắn vào mỗi `Stmt` dict
qua key `'src_line'`. Emit `.line {src_line} '{source_path}'` tại 1 điểm
DUY NHẤT — vòng lặp dispatch trung tâm `_codegen_stmts` — nên KHÔNG cần
sửa bất kỳ file nào trong ~50 file `il_features/*.py`. `assemble_il_to_exe`
thêm `/debug` vào lệnh gọi `ilasm.exe` khi bật, sinh Windows PDB cổ điển
(đã xác minh thật qua probe `ilasm.exe /debug`, chữ ký `"Microsoft C/C++
MSF 7.00"`).

**Tech Stack:** Python 3 (compiler), CIL text lắp qua `ilasm.exe`
(`.NET Framework mscorlib v4.0.30319`), Windows PDB cổ điển (KHÔNG phải
Portable PDB — Source Link không áp dụng).

Trong `compiler/il_codegen.py`, thay chữ ký + phần cuối hàm:

```python
def _strip_lines(body_lines, start_line=None):
    """Bo dong trong, dong chu thich '#' va DOCSTRING... (giu nguyen
    docstring cu, them doan sau)

    start_line (Debug PDB, 2026-08-12): so dong TUYET DOI (1-based) cua
    body_lines[0] trong file nguon goc (tu ast's .lineno) - neu co, ham
    nay TRA VE THEM 1 list line_nos CUNG DO DAI voi ket qua chinh, moi
    phan tu la so dong tuyet doi tuong ung. None neu khong truyen
    start_line (cac noi CHUA can, vd generator/async closure body o Task
    khac cua plan nay)."""
    out = []
    line_nos = [] if start_line is not None else None
    i = 0
    while i < len(body_lines):
        raw = body_lines[i]
        body = raw.strip()
        if not body or body.startswith('#'):
            i += 1
            continue
        delim = None
        for d in ('"""', "'''"):
            if body.startswith(d):
                delim = d
                break
        if delim is not None:
            if not (len(body) >= 2 * len(delim) and body.endswith(delim)):
                i += 1
                while i < len(body_lines) and delim not in body_lines[i]:
                    i += 1
            i += 1
            continue
        indent = len(raw) - len(raw.lstrip(' '))
        line_no_here = (start_line + i) if start_line is not None else None
        body = _strip_trailing_comment(body)
        while _bracket_depth(body) > 0 and i + 1 < len(body_lines):
            i += 1
            body = body + ' ' + body_lines[i].strip()
        out.append((indent, body))
        if line_nos is not None:
            line_nos.append(line_no_here)
        i += 1
    return (out, line_nos) if start_line is not None else (out, None)
```

Lưu ý QUAN TRỌNG (đã ghi trong spec, mục "Điểm cần xác minh"): nếu
`_rewrite_nested_defs` (gọi trong `_body_source_lines`, dòng 266) sửa ĐỔI
SỐ DÒNG của `body_lines` (thêm/bớt phần tử, không chỉ sửa text tại chỗ) —
`line_no_here = start_line + i` sẽ SAI lệch từ điểm đó trở đi. Đọc
`_rewrite_nested_defs` (tìm bằng `grep -n "_rewrite_nested_defs" tkv_compile.py`)
để xác nhận nó CHỈ sửa text từng dòng TẠI CHỖ (không `del`/`insert` vào
`lines`) — nếu XÁC NHẬN đúng vậy, công thức trên an toàn; nếu KHÔNG, cần

- [ ] **Step 3: Sửa `_parse_block` nhận `line_nos`, gắn `stmt['src_line']`**

```python
def _parse_block(lines, pos, indent_level, sig, known_shapes, line_nos=None):
    stmts = []
    while pos < len(lines) and lines[pos][0] == indent_level:
        line = lines[pos][1]
        start_pos = pos
        matched = None
        for _name, fn in LINE_PARSERS:
            matched = fn(line, lines, pos, indent_level, sig, known_shapes, _parse_block)
            if matched is not None:
                break
        if matched is None:
            raise SyntaxError(f'il_codegen: khong dich duoc dong: {line!r}')
        stmt, pos = matched
        if line_nos is not None and start_pos < len(line_nos):
            stmt['src_line'] = line_nos[start_pos]
        stmts.append(stmt)
    return stmts, pos
```

Lưu ý: `line_nos` không truyền tiếp vào các lời gọi `_parse_block` ĐỆ QUY
bên trong từng `_lp_*`/`try_parse_*` (vd `try_parse_for`'s `parse_block_fn`
callback dùng cho THÂN của `for`/`if`) — CHẤP NHẬN ĐƯỢC ở Task này (thân
khối lồng nhau sẽ có `src_line=None`, KHÔNG lỗi, chỉ đơn giản KHÔNG có
